# Requisitos y soporte técnico de AulaNova

## Navegadores y dispositivos

La plataforma web funciona con las dos versiones estables más recientes de
Chrome, Edge, Firefox y Safari. Internet Explorer no es compatible. Para
computadoras se recomienda una pantalla de al menos 1280 por 720 píxeles,
cuatro gigabytes de memoria y un sistema operativo que todavía reciba
actualizaciones de seguridad.

Las clases en vivo requieren una conexión estable de diez megabits por segundo
de descarga y tres de subida. La cámara es opcional, excepto durante
evaluaciones supervisadas. El micrófono debe habilitarse desde los permisos
del navegador. Si el audio falla, se recomienda cerrar otras aplicaciones que
usen el dispositivo, volver a seleccionar la entrada correcta y recargar la
sala.

La aplicación móvil permite ver grabaciones, leer materiales y responder
foros. La entrega del proyecto final y las evaluaciones supervisadas deben
realizarse desde un navegador de escritorio. Los videos descargados para uso
sin conexión caducan a los treinta días y no pueden copiarse fuera de la
aplicación.

## Solución de problemas

Ante una pantalla en blanco, el primer paso es abrir una ventana privada. Si
allí funciona, se deben borrar las cookies y el almacenamiento del sitio
`aulanova.example`. También conviene desactivar temporalmente bloqueadores de
anuncios o extensiones que modifiquen scripts. Borrar el historial completo no
es necesario.

El código de error AV-102 indica que el navegador bloqueó la reproducción
protegida. Se resuelve habilitando contenido protegido y verificando que la
fecha y hora del equipo sean correctas. El error UP-413 aparece cuando una
entrega supera el límite de cien megabytes; en ese caso el archivo debe
comprimirse o compartirse mediante el campo de enlace permitido por la
consigna.

Si una clase en vivo se corta, el sistema intenta reconectar durante sesenta
segundos. El progreso de los videos grabados se guarda cada quince segundos.
Una caída antes de esa sincronización puede hacer que el reproductor retroceda
unos segundos, pero no elimina el avance completo.

## Canales y horarios

El centro de ayuda está disponible dentro de la plataforma en
**Ayuda > Crear ticket**. La atención humana funciona de lunes a viernes de
9:00 a 18:00, hora de Argentina, excepto feriados nacionales. Los tickets
generales tienen un plazo objetivo de respuesta de un día hábil.

Los incidentes que impiden el acceso de todos los estudiantes a una clase en
curso se clasifican como críticos y se responden dentro de dos horas. Una
duda sobre contenidos, una corrección o una fecha de entrega se deriva al
tutor y no se considera incidente técnico.

Para diagnosticar un problema, el ticket debe incluir una descripción breve,
los pasos para reproducirlo, la hora aproximada, navegador, sistema operativo
y una captura donde no aparezcan contraseñas ni datos de pago. El número de
orden solo se solicita para problemas de facturación.

## Estado del servicio y privacidad

Las interrupciones generales se publican en `status.aulanova.example`. Antes
de abrir varios tickets por el mismo síntoma se recomienda revisar ese panel.
Las actualizaciones del incidente se agregan allí hasta la resolución.

Soporte puede pedir registros de consola, pero nunca una contraseña, un código
de verificación vigente ni acceso remoto al equipo. Las capturas adjuntas se
conservan durante noventa días y luego se eliminan. El usuario puede pedir la
eliminación anticipada una vez cerrado el caso.
